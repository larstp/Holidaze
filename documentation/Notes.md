## CSS Loaders

Source: [CSS Loaders](https://css-loaders.com/) by [Afif13](https://github.com/Afif13/)

The loading spinner is adapted from the CSS loader examples and recoloured with the project token `var(--logo-color)`. The implementation was integrated into the reusable `PageLoader` component and includes reduced-motion support.

## React DayPicker

Source: [React DayPicker](https://daypicker.dev/) - [GitHub](https://github.com/gpbl/react-day-picker)

License: MIT

Used for the Venue availability calendar, Manager Overview calendars, and customer trip calendars. The project adds its own styling, booked-date modifiers, disabled dates, and date-selection behavior.

## FullCalendar

Source: [FullCalendar](https://fullcalendar.io/) - [GitHub](https://github.com/fullcalendar/fullcalendar)

License: MIT for the packages used in this project.

Used for the Incoming Bookings calendar. The project uses the FullCalendar core, DayGrid, and interaction packages and applies its own event styling, venue sections, customer summaries, and past-booking states.
